# Aakash Jha — Portfolio

A personal developer portfolio built to showcase my **projects, skills, and experience** in one place.

The goal was to keep things simple — a clean interface, responsive design, and enough detail to get a quick sense of what I build and how I work.

## Tech Stack

- React.js
- React Icons
- Tailwind CSS
- Lucide React

## Highlights

- Selected projects with relevant details
- Technical skills and experience
- Responsive across devices
- Subtle animations and interactions
- Clean, minimal UI
